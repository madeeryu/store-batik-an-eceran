Setup Aplikasi Eceran

📋 Tentang Halaman Ini

Halaman ini menjalankan setup awal aplikasi eceran SEKALI saja. Jalankan langkah-langkah berikut secara berurutan dari atas ke bawah. Setiap langkah aman dijalankan ulang (idempotent) — data yang sudah ada tidak akan ditimpa.

1

Migrasi Field Produk Grosir → Eceran

Menambahkan field jual_di, harga_eceran_pcs, modal_eceran_pcs, dan pcs_per_kodi ke semua dokumen di koleksi produk yang belum memilikinya. Dokumen yang sudah punya field tersebut akan dilewati.

💡 Nilai default ini hanya dipakai untuk produk yang BELUM punya field tersebut. Edit per produk nanti di Master Produk untuk menyesuaikan harga & modal sebenarnya.

2

Buat 3 Mitra Default (Siti Isa, Lilis, Aal)

Membuat akun Firebase Auth + dokumen mitra/{id} + dokumen users/{uid} untuk 3 mitra sekaligus. Jika nama sudah ada di koleksi mitra, langkah itu dilewati. Owner yang sedang login TIDAK akan ikut logout.

💡 Email & password sementara akan ditampilkan di log setelah selesai. Catat dan berikan ke masing-masing mitra. Password bisa diubah lewat "Reset Password" di Master Mitra.

3

Inisialisasi Stok Keranjang Kosong

Membuat dokumen stok_eceran/{mitra_id}_{produk_id} untuk semua kombinasi mitra aktif × produk eceran. Stok awal = 0, target = 0. Anda bisa edit target nanti di halaman Set Target.
4

Verifikasi Index Firestore & Security Rules

Index Firestore dan Security Rules tidak bisa dibuat dari aplikasi karena memerlukan hak admin. Gunakan Firebase CLI. Lihat Bagian B di tutorial ini untuk panduan deploy via CLI. Tombol di bawah hanya menjalankan tes query untuk mendeteksi index yang kurang.

✅ Selesai?

Setelah semua langkah hijau (kecuali Langkah 4 yang dikerjakan via CLI), aplikasi siap digunakan untuk operasional sehari-hari. Halaman setup ini tetap bisa diakses lewat URL ...index.html#setup jika perlu jalankan ulang (semua operasi aman diulang).
